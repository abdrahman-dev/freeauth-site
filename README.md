# OpenAuth

Bare-bones Vite + React + TypeScript scaffold with Tailwind CSS. No pages, component library, router, icons, or state management yet — those decisions come later, deliberately.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run lint` — lint with ESLint
- `npm run preview` — preview the production build

## UI Guide

Before writing any UI code, read docs/ui-guide.md — it is the canonical visual source of truth for this project. Do not introduce colors, spacing, radii, or typography choices not defined there without updating the guide first.
